# Glossary

> **Audience:** everyone · **Last reviewed:** 2026-10-10

| Term | Meaning |
|---|---|
| **Action title** | A slide title that states the conclusion as a full sentence ("Churn is concentrated in the first 90 days"), not a topic ("Churn"). |
| **Brief** | `brief.yaml`: goal, ask, audience, task, usage and choice — the input to the workflow. |
| **Checkpoint (CP1–CP4)** | A point where the user must approve before the workflow continues. |
| **Contact sheet** | All slides of a deck on one image; used to compare templates. |
| **Copy-fitting** | Stepping text size down within the theme's limits, then asking for a rewrite if it still does not fit. |
| **Diagnostic** | A check result with a stable `SC-*` code, severity, JSON pointer, measured/limit and hint. |
| **Engine** | A renderer from Scene IR to a file format (pptxgenjs, native PDF, html, pptx-convert, resvg, artifact-tool). |
| **Exhibit** | The visual on a slide that proves the title (chart, table, matrix…). |
| **Frame** | The fixed slide regions: tracker, title, lead, body, source line, footer, page number. |
| **Ghost deck / ghost slide** | Slides with final action titles and exhibit sketches but no content yet. |
| **Governing thought** | The single answer the deck argues; first in the pyramid. |
| **Layout** | An exhibit type with a content contract and a compose function. |
| **MECE** | Mutually exclusive, collectively exhaustive — a grouping with no overlaps and no gaps. |
| **Metric-compatible font** | An open font with the same glyph advance widths as a system font, used for exact measurement. |
| **Scene IR** | The engine-neutral description of every slide: positioned primitives with pre-broken text. |
| **SCR / SCQA** | Situation, Complication, (Question), Resolution — a way to open an argument. |
| **Storyline** | The shape of the argument for a task: sections and slots with purposes and preferred layouts. |
| **Template** | Storyline × theme, as offered at checkpoint 2. |
| **Theme** | Colour roles, chart palette, fonts, type scale, decor and chrome. |
| **Tracker** | The small section label above an action title. |
| **Variant** | A different content shape of the same layout (e.g. `scr` vs `key-messages`). |
