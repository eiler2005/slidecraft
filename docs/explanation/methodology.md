# Methodology

> **Audience:** deck authors and reviewers · **Last reviewed:** 2026-10-10

The rules SlideCraft applies are kept in one place, [`library/references/`](../../library/references/README.md), so skills, agents and people read the same text:

- [Writing standard](../../library/references/writing-standard.md) — Pyramid Principle, SCR, MECE, action titles, sourcing.
- [Visual standard](../../library/references/visual-standard.md) — grid, type, one-accent rule, charts, tables, density.
- [Exhibit selection](../../library/references/exhibit-selection.md) — message → layout decision table.
- [Patterns](../../library/references/patterns.md) — management (M) and visual (V) patterns and their status.
- [Review](../../library/references/review.md) — partner-grade review and render QA.
- [Storytelling](../../library/references/storytelling.md) — narrative decks and talks.
