# Apply your brand

> **Audience:** teams with brand guidelines · **Last reviewed:** 2026-10-10

Today (v0.1): create a theme with your colours and a measurable font family ([add a theme](add-theme.md)), set the footer in `deck.yaml` (`footer: Contoso · Confidential`) or `brief.yaml` (`brand.footer`), and select it with `theme:` or `brand.theme`.

Mapping guidelines to tokens:

| Brand guide | Theme token |
|---|---|
| Primary brand colour | `accent` (use for one highlight per slide) |
| Dark text colour | `ink`, `titleInk` |
| Secondary / neutral greys | `muted`, `rule`, `surface` |
| Light tint of primary | `accentSoft` |
| Data palette | `chart` (primary first) |
| Corporate font | nearest measurable family (Arial / Georgia / Times New Roman) until brand-font calibration lands |

Planned (M3): import colours, fonts, logo and the slide master from your `.potx`, with a calibration report for custom fonts. See [ROADMAP](../../ROADMAP.md).
