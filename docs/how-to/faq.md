# FAQ

> **Audience:** everyone · **Last reviewed:** 2026-10-10

**Is the PowerPoint really editable?** Yes — text boxes, tables and charts are native objects; charts carry their data; every slide has speaker notes; themes use slide masters. Only decorative backgrounds are images.

**Will my text overflow in PowerPoint?** SlideCraft measures with fonts metric-compatible with Arial, Georgia and Times New Roman and was calibrated against PowerPoint: 98.6% identical line breaks and no case where PowerPoint needed more lines. Fonts must be installed on the viewing machine.

**Can I use my company template?** Today, by recreating its colours and font family as a theme. `.potx` import is planned (M3).

**Does it make up numbers?** No. Every number must cite a source; illustrative data is labelled; agents are instructed to ask rather than invent.

**Do I need Claude Code?** No. The CLI and `AGENTS.md` work with any agent or by hand.

**Does it send my data anywhere?** The CLI makes no network calls; your decks stay in `./slidecraft/`. Claude Code itself uses your Claude account as usual.

**Why not Google Slides?** Not yet. PPTX imports into Google Slides; native export is on the wish list.

**Is artifact-tool required?** No. It is an optional engine for Codex users and is proprietary; the default engines are open-source libraries bundled with SlideCraft.

**Which languages?** Any language whose characters exist in the bundled fonts — Latin, Greek and Cyrillic today.
