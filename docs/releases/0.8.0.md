# SlideCraft 0.8.0 — native diagrams

SlideCraft now includes **73 layouts**: 27 new native diagram layouts and six additional analytical chart variants. Heatmaps, treemaps, Sankey flows, architecture deltas, swimlanes, journeys, blueprints, sequence/state diagrams and data models export as editable PowerPoint shapes and text, with shared geometry for HTML and vector PDF.

- Import a bounded Mermaid, draw.io or Excalidraw subset with `slidecraft import-diagram`; its loss ledger records what was preserved or omitted.
- Use `readability: present` for larger type, with diagnostics when content needs to be shortened or split.
- Explore two synthetic 33-slide galleries in light and dark themes on the [website](https://eiler2005.github.io/slidecraft/#diagrams).
- PDF.js 6 compatibility preserves PDF text, colours and filled areas and releases resources on success or failure.
- Biome, Vitest and Zod are updated; release metadata is synchronized and npm publishing uses a verified tag through GitHub Actions.

**Runtime change:** Node.js **22.13 or newer** is required. CI checks the standalone bundles on the minimum version, Linux, macOS and Windows.

The new diagram galleries have been reviewed in Chrome and the PPTX objects checked structurally. Actual PowerPoint rendering, manual object editing and 95% parity remain unverified because Office automation failed during review. [Evidence and limits](../research/diagram-design-implementation-2026-10.md).

Update with `npm install -g @eiler2005/slidecraft@0.8.0`, or run `npx -y @eiler2005/slidecraft@0.8.0 --version`.
