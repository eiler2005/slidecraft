# Methodology library

The rules SlideCraft's skills and agents apply. They are written for people first and loaded by agents on demand.

| Reference | What it covers | Used by |
|---|---|---|
| [writing-standard.md](writing-standard.md) | Pyramid Principle, SCR, MECE, action titles, fact vs proposal vs unknown, sourcing and number style | storyline-architect, action-title-writer, ghost-deck-skeleton, deck-spec |
| [visual-standard.md](visual-standard.md) | Grid, type hierarchy, one-accent rule, chart and table rules, density, consistency, accessibility | exhibit-chooser, partner-review-checklist |
| [exhibit-selection.md](exhibit-selection.md) | Message → exhibit decision table mapped to SlideCraft layouts and variants | exhibit-chooser, deck-spec |
| [patterns.md](patterns.md) | Management (M01–M10) and visual (V01–V15) patterns, what is implemented, what is in the backlog | storyline-architect, contributors |
| [review.md](review.md) | Partner-grade review order, blockers/majors/minors, automated checks and render QA | review skill, partner-reviewer, copy-fitter |
| [storytelling.md](storytelling.md) | Narrative arc for keynotes and experience-sharing talks, slide patterns, pitfalls | storyline-architect, exhibit-chooser |

Storylines (`../storylines/*.yaml`) and themes (`../themes/*.json`) are data; their generated reference lives in [`docs/reference/`](../../docs/reference/). `../catalog.json` is generated by `slidecraft gen`.
